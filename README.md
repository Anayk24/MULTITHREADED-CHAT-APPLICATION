# MULTITHREADED CHAT APPLICATION
📌 Project Description

This project is a Multithreaded Chat Application in Java that allows multiple clients to communicate with a server simultaneously using socket programming and multithreading.

The server handles multiple client connections at the same time, while each client can send and receive messages in real time through the terminal.

# Features

Real-time messaging between multiple clients

Multithreaded server to handle many users simultaneously

Simple command-line interface

Built using Java Socket Programming

Lightweight and easy to run

# Technologies Used:

Java

Socket Programming

Multithreading

Command Line Interface

📂 Project Structure
Server.java   → Handles client connections and message broadcasting  
Client.java   → Connects to server and sends/receives messages
